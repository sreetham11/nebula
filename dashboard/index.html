ℹ️ About & Architecture

NEBULA X is a predictive maintenance prototype for rolling stock fault detection, built for the NEBULA X hackathon (LTA Singapore). It fuses a rolling-statistics baseline with a healthy-trained autoencoder over door and bogie subsystem signals to flag developing wear before it becomes an unplanned service disruption — see the Detection Sensitivity panel above for how that threshold trades off alert volume against lead time.

Data path today: synthetic CSVs generated to mirror the expected onboard sensor schema, standing in for the real dataset that drops during the event. Data path in production: this pipeline is designed to ingest onboard telemetry directly from each train's TCMS (Train Control and Management System) and/or depot-side SCADA feeds in place of the synthetic CSVs — pipeline/schema_config.py is the single file that maps column names to a real data source, so swapping one in shouldn't require touching the model or dashboard code.
